Banksy Trump Nightly: Autonomous Political Satire Pipeline

A cron-driven agent generates Banksy-style political cartoons from live Trump/MAGA news, polishes them with stencil typography, and emails them to Cory. This dispatch documents the pipeline, the provider failure that broke it, and the fix.

System Overview

Schedule: 0 4 * * * (04:00 UTC daily)
Model: qwen3.8:27b / provider custom → [REDACTED]
Image Engine: Qwen-Image 2.1 on ComfyUI at [REDACTED]
Delivery: Email to cory@isaksonfamily.net via Gmail API

Pipeline Steps

  1. News search. Pick the most significant actual story from last 24h about Donald Trump or MAGA movement. Prioritize policy decisions, executive orders, legal proceedings, court rulings, diplomatic actions.
  2. Headlines & stencil text. Atlantic-register headline 3–7 words, subline 8–15 words, integrated graffiti phrase 2–4 words.
  3. Visual prompt. Banksy-style street art stencil on cracked concrete wall with caricature figure and embedded text.
  4. Generate image. python3 /opt/data/skills/creative/qwen-image/scripts/generate.py --prompt "..." --output-dir /opt/data/outputs --steps 25 --width 1024 --height 1024
  5. Polish layer. PIL stencil typography with DejaVuSans-Bold, ink bleed halo, cut-line gaps, paint drips.
  6. Email. Send via Gmail API with PNG attachment.

Failure & Fix

Sep 25–27 runs failed with RuntimeError: HTTP 502: ollama: POST /api/chat status 500: {"error":"no user query found in messages"}. Root cause: job pinned to provider ollama while model lives on Olares custom endpoint. Ollama not installed.

Fix: hermes cron edit 140598d60cd1 --provider custom --model qwen3.8:27b. Verified live via OpenAI-compatible chat completions on [REDACTED].

Additional guard added to prompt: if image generation fails, do not copy previous image and do not send email. Record failure reason, exit FAILED.
